
# 仮想環境・パッケージ管理について

このリポジトリでは、Python仮想環境（.venv/）やsite-packages（パッケージ群）はgit管理対象外です。

## 初期セットアップ手順
1. Python 3.12 以上をインストール
2. 仮想環境作成
	```bash
	python3 -m venv .venv
	source .venv/bin/activate
	```
3. 必要パッケージのインストール
	```bash
	pip install -r requirements.txt
	```

## 再現性のためのファイル
- requirements.txt（必須パッケージ一覧）
- README.md（セットアップ手順・実行方法）

## 注意
- .venv/ や site-packages/ は .gitignore で除外されています。
- 仮想環境やパッケージは各自セットアップしてください。

## openpilotサブモジュール補完・差分パッチ適用手順

### 1. openpilotサブモジュールの初期化

まず、リポジトリをクローンした直後に以下を実行してください。

```bash
git submodule update --init --recursive
```

> **注意:**
> - 既存の`openpilot`ディレクトリがある場合は、必ずバックアップ・削除してからサブモジュール化してください。
> - サブモジュールは公式openpilotリポジトリのクリーンな状態で取得されます。

### 2. 差分パッチの適用

`openpilot_patch_full.patch`と`openpilot_patch_apply.sh`が本リポジトリ直下にあることを確認し、
以下のコマンドで公式との差分を反映します。

```bash
bash openpilot_patch_apply.sh
```

> **注意:**
> - パッチ適用前に`openpilot`サブモジュールの内容が最新（`git submodule update`済み）であることを確認してください。
> - パッチ適用で競合やエラーが出た場合は、`openpilot_bak`等のバックアップから手動で差分を確認してください。
> - サブモジュールのバージョンが変わった場合、パッチが適用できないことがあります。その場合は再度パッチを作り直してください。

### 3. よくあるトラブル
- サブモジュールの初期化に失敗する場合は、`.gitmodules`や`.git/config`の記述を確認してください。
- openpilot配下に未管理ファイルがあるとサブモジュール化できません。事前に退避・削除してください。
- パッチ適用後に動作確認を必ず行ってください。

---

この手順で、サブモジュールベースで公式との差分を再現できます。
